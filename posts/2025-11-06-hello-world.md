Welcome to my personal blog website. The objective of this website was to be
relatively simple and yet powerful for whatever I might want to do in future. A
core feature that I wanted was to be able to write posts in Markdown, as that is
my preferred note taking language. This is achieved by parsing the Markdown into
a JSON summary and HTML posts.

Many aspects of Markdown are preserved using this method. For example this HTML
generated from Markdown can make text **bold**. I've found that most things in
Markdown translate really well (apart from tables). This is all thanks to the
great work on the following projects:

- [gray-matter](https://github.com/jonschlinkert/gray-matter)
- [remark](https://github.com/remarkjs/remark)
